This release is about what a listing is worth: it reads advert bodies that boards
only hint at, states what an advert requires rather than what it might mention,
and stops calling a hidden posting a bad one. Two sources are gone because they
could only ever contribute a title and a dead link.

### Sources

- **Interamt** joins the German set, the public-sector board. Its search is a
  Wicket form rather than a URL, and its detail links are session-bound
  callbacks, so the app asks the form and opens adverts at the address that
  works. A board that was never given a query now says so instead of reporting
  zero results.
- **EURES** adverts open again. The stored links were missing the detail segment
  and the display-language parameter, so every one of them answered 404 while the
  listing itself was alive. The connector, the liveness probe and every stored
  URL were corrected, and 1,205 rows that had been hidden came back.
- **Watchlist** follows an employer's own careers page. A page that is a single
  plain-text announcement produces one card, which is why firms with no real
  listing are skipped rather than followed.
- **englishjobs and talent.com are removed**, not disabled. Both redirect to a
  client-rendered page whose signed links answer 403, so neither could ever
  produce an advert body. Their stored rows are hidden with the reason.
- **Jobware** is read from the page's own data string, including the facts line
  where the contract is stated, and falls back to the longest prose block when no
  heading matches. The old parser had been storing a title and a date.
- **myscience** adverts are read whole. The body used to be cut at 6,000
  characters, which fell before the "Unser Angebot" section and hid the contract.

### Advert bodies

- **Fill missing advert text** is a job of its own: a queue that walks stored
  postings whose board sent only a teaser, reads the advert, stores it and
  re-scores. It has its own controls, progress line and setting, and it works the
  rows that matter first. This is what turns a board that ships no body from a
  title-only guess into a real match.
- A scan now fetches the body before judging a source that ships none, within a
  per-scan budget, so a new posting is scored on its advert rather than its title.
- Advert text has one shape at storage whatever the source sends: Greenhouse
  sends HTML, Jobware escaped line breaks, Interamt rich text. Tags no longer
  reach the search index or the scorer.
- The source audit asks every connector the same questions and tells a **lazy**
  connector from a broken one: a source that produces prose on a detail fetch is
  not broken, it is unfilled.

### Matching

- **`require_ai`**: an optional filter that keeps only adverts which state that
  working with AI is a requirement. It reads the clause around the mention and
  requires the requirement words nearby, so a bulleted skills list does not make
  every advert a requirement. This is the one filter where silence is not kept:
  an advert with no readable body cannot state the requirement.
- Filters decide visibility, not the score. The AI and language gates used to
  return before a point was awarded, so every filtered row kept score 0 and a
  whole board read as "consistently very low" while its adverts were merely
  hidden. The score is now computed first; the filter is applied after.
- Contract mapping: an explicit "Befristungsart: Befristet" beats the word
  "Festanstellung" elsewhere on the page.

### Cards and filters

- **New** marks an advert that arrived within a window in hours, 24 by default,
  set in Settings. It is independent of the scan rhythm: tied to scans, an hourly
  scan would clear it within the hour.
- The status dropdown said **New** for "nobody has triaged this", which is a
  different thing and looked like it did nothing. It now says **Untouched**, and
  the badge has its own filter beside Fresh from the source and Closing soon.
- **Closing watch**: a bar on start names adverts whose stated deadline falls
  within the next fortnight.
- **Source health**: per board, the last run, the error itself, and a grey dot
  for a board that has never been scanned. Zero is a signal.
- **Reject suggestions**: titles you keep dismissing become a one-click deny term,
  and the card says why it is empty instead of vanishing.
- A closed advert dims and strikes the whole card, not only its pill.

### Duplicates

- One post carried by two boards is matched even when the boards decorate the
  title differently: gender markers, a hyphen inside a compound, a trailing city,
  "Bremen" against "Bremen (DE)", and `&amp;` against `&`. Rows are bucketed by
  employer first, so a generic title shared by two firms in one city no longer
  blocks the real pair behind it.
- The copy that survives is the best one, not the first one scanned: the
  employer's own board, then the fullest advert, then the higher score. Scan
  order used to decide, which picked the thinner copy as often as the better one.
- One pill per board, however many rows that board holds.
