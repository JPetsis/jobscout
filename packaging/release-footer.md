Unsigned builds. Each platform shows a first-run warning; the exact sequence to
get past it is in `docs/INSTALL.md`.

| platform | file |
|---|---|
| macOS (Apple Silicon) | `jobscout-macos-arm64.zip` |
| macOS (Intel) | `jobscout-macos-x86_64.zip` |
| Windows (x86_64) | `jobscout-windows-x86_64.zip` |
| Linux (x86_64) | `jobscout-linux-x86_64.tar.gz` |
| Linux (arm64) | `jobscout-linux-arm64.tar.gz` |

Your data lives in `~/.jobscout/` (`C:\Users\<you>\.jobscout\` on Windows) and
is never touched by installing, updating or removing the app.
